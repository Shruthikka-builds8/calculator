## 📌 About The Project

A simple command-line calculator built with Python that performs basic arithmetic operations. Clean, beginner-friendly, and fully functional!

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🚫 Handles division by zero errors
- 🔁 Runs continuously until you choose to exit

---

## 🚀 How To Run

**1. Clone the repository**
```bash
git clone https://github.com/Shruthikka-build8/calculator.git
```

**2. Navigate into the folder**
```bash
cd calculator
```

**3. Run the program**
```bash
python calculator.py
```
